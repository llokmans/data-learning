# data-learning

My first steps with NumPy and pandas, the two libraries most Python data work is built on.

- **`arrays.py`** (NumPy): creating arrays, vectorised maths on a whole array at once, `sum`, `mean`, `max`, and boolean filtering (`numbers[numbers > 2]`).
- **`data.py`** (pandas): building a DataFrame from a dictionary, selecting a column, filtering rows by a condition, and taking a column average.

## Run it

```
pip install numpy pandas
python arrays.py
python data.py
```

These foundations are used for real in [data-cleaning](https://github.com/llokmans/data-cleaning) and [weather-pipeline](https://github.com/llokmans/weather-pipeline).
